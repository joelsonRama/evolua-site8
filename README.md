# Site institucional - Evolua Tecnologia

Site estático (HTML + CSS + JS, sem build) para www.evoluatecnologia.com.br.

## Páginas
- `index.html`: início
- `evolua-ticket.html`, `evolua-parking.html`, `evolua-pdv.html`: sistemas
- `acesso.html`: Painel do Cliente e Painel do Vendedor
- `contato.html`: contato (o formulário abre o WhatsApp com a mensagem pronta)

## Contatos
Edite o bloco `EVOLUA` no começo de `assets/js/main.js` (WhatsApp, telefone, e-mail, Instagram e cidade).
Campo vazio não aparece no site.

## Publicar no Cloudflare Pages
Workers & Pages > Create > Pages > Connect to Git > este repositório.
- Framework preset: None
- Build command: (vazio)
- Build output directory: (vazio)
