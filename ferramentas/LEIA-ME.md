# Ferramentas do site (não publicadas)

Branch só com os scripts usados para gerar o site e as imagens. Não vai para o site.

- `gerar_site.py`: gera todas as páginas HTML a partir de um só arquivo (cabeçalho, rodapé, textos). Ajuste o caminho `OUT` e rode `python3 gerar_site.py`.
- `imagens/`: montagem das telas nas maquininhas, fichas saindo da impressora, celular com impressora.
- `instagram/`: 30 posts (`make.py`) e 40 stories (`stories.py`), renderizados com Playwright (`render.js`, `rs.js`).
- `painel-demo/`: dados fictícios usados para tirar os prints do painel.
